## Description
GuitarFret is a focused, lightweight guitar chord analysis tool.

Tap one position per string on the fretboard and GuitarFret immediately identifies the current chord shape. It shows the root, the interval from each note to the root, and the reason those notes form the detected chord.

Use it to:

- Check the name of a chord shape while practicing
- Understand roots, thirds, fifths, sevenths, and chord structure on the fretboard
- See how open strings, muted strings, and different positions affect the result
- Explore alternate voicings with chord diagrams

GuitarFret is not a course app. It does one thing: lets you tap the fretboard and clearly see why the chord is what it is.

Key features:

- Real guitar fretboard layout for iPhone portrait and iPad landscape
- Real-time chord recognition
- Interval labels shown directly on the fretboard
- Open strings, muted X strings, and one-note-per-string modeling
- Playback for individual notes and full chords
- Physical string vibration feedback
- Alternate voicings with chord diagrams
- Local-only app, no account required

One-time purchase. No subscription.
